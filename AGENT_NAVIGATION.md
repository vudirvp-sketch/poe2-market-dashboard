| `src/data/` | `cache-snapshot.json` | **READ-ONLY — NEVER edit manually** |

## 2. Build & Run Commands

```bash
npm install && npm run dev        # Frontend (port 3000)
npm run build && npm run test     # Build + Jest
pytest tests/ -v                  # Backend tests
npx tsc --noEmit                  # TypeScript type check

# Backend (start.sh creates .venv automatically)
PYTHONPATH=. .venv/bin/python -m uvicorn backend.main:app --reload --port 8000

# Generate TypeScript types from OpenAPI schema
PYTHONPATH=. python -c "import json; from backend.main import app; json.dump(app.openapi(), open('openapi_schema.json','w'), indent=2)"
npx openapi-typescript openapi_schema.json --output src/lib/api-types.ts
```

## 3. Critical Rules

1. **Types in `src/lib/types.ts` ONLY** — no duplicates elsewhere
2. **Backend responses MUST use snake_case** — flipper-proxy `transformKeys()` converts to camelCase
3. **All API routes use /api/v1/ prefix** (Phase 4.2) — old /api/ paths are removed
4. **X-API-Version: 1 header** on all responses — APIVersionMiddleware
5. **CPU-bound Python → `run_in_executor()` with timeout** — never block event loop
6. **ProcessPoolExecutor: picklable args only** — no sqlite3.Connection, no EventManager
7. **PriceLogs are REVERSE chronological** — always sort before charting
8. **Never touch `cache-snapshot.json`** — generated by script
9. **Never hardcode league names or currency categories** — use `config.yaml`
10. **`pipeline_cache` via `get_pipeline_cache()` in every endpoint** — not module-level
11. **Bridge uses `python -m uvicorn`** — `getUvicornArgs()` must return `["-m", "uvicorn"]`
12. **Linux build: remove `.venv`** — Turbopack panics on symlinks
13. **Do NOT use `/* turbopackIgnore: true */`** — breaks chunk creation
14. **CI uses Python 3.12** — do NOT change to 3.13+
15. **FLIPPER_WORKERS env var** — controls ProcessPoolExecutor workers (default: 1)
16. **Ritual Omens: ratio=1** — cannot be reforged, price-comparison only
17. **Query keys MUST use `QUERY_KEYS` from `providers.tsx`** — no ad-hoc string keys
18. **Exchange pair queries MUST use `useExchangePairs()` hook** — no inline fetchApi
19. **Cross-rate computation MUST use `useCrossRates()` hook** — no inline buildRelativePriceMap/selectAnchor in components
20. **Currency item queries MUST use `useCurrencyItems()` / `useAllItems()` / `useItemCategories()`** — no inline fetchApi
21. **Unique item queries MUST use `useUniqueItems()` hook** — no inline fetchApi
22. **Prefetch on league/realm change MUST use `usePrefetch()` hook** — no manual prefetchQuery() in components
23. **Batch queries MUST use `useBatchQuery()` / `useInitialBatch()`** — no manual batch fetch in components
24. **Heavy tabs MUST be lazy-loaded via `next/dynamic`** — FlipsTab, OptimizerTab, AnalystTab, LiquidChainTab, CurrencyGraphTab, WatchlistTab
25. **SSE price stream MUST use `usePriceStream()` hook** — no manual EventSource in components
26. **SSE is complement to polling, NOT replacement** — React Query refetchInterval continues working
27. **Compression is transparent** — CompressionMiddleware handles gzip/brotli automatically; batch internal requests use `Accept-Encoding: identity`
28. **Response models in `backend/api/response_models.py`** — all endpoints have response_model= for OpenAPI
29. **`src/lib/api-types.ts` is auto-generated** — regenerate via openapi-typescript, never edit manually

### API Versioning (Phase 4.2)

All endpoints use `/api/v1/` prefix. All responses include `X-API-Version: 1` header.

### Compression (Phase 3.3)

All JSON endpoints support transparent gzip/brotli compression:
- Client sends `Accept-Encoding: gzip, deflate, br`
- Middleware responds with `Content-Encoding: br` (preferred) or `Content-Encoding: gzip`
- SSE streams (`text/event-stream`) are NOT compressed
- Responses <500 bytes are NOT compressed
- `Vary: Accept-Encoding` header added for cache correctness

### Typed API Client (Phase 4.3)

TypeScript types are auto-generated from OpenAPI schema:
- Source: `backend/api/response_models.py` (Pydantic models)
- Schema: `openapi_schema.json` (generated from FastAPI)
- Types: `src/lib/api-types.ts` (generated via openapi-typescript)
- Regenerate: see Build & Run Commands section
