Work Log:
- Root cause: `asyncio.get_event_loop()` was deprecated since Python 3.10 and REMOVED in Python 3.14. The 12 call sites in `test_daily_stats_persistence.py` used `asyncio.get_event_loop().run_until_complete(coro)` to seed/close the HistoricalStore in sync test methods.
- **Fix applied to `tests/test_daily_stats_persistence.py`:** (1) Added a module-level `_run(coro)` helper that calls `asyncio.run(coro)` — creates a fresh event loop per call. Safe for HistoricalStore because aiosqlite connections support cross-loop usage. (2) Replaced all 12 `asyncio.get_event_loop().run_until_complete(...)` call sites with `_run(...)`. Test-only change — no production code touched.
- **P10 Phase 2 + TD-3 production verification (code-path audit):** All 4 sub-items verified via existing tests + code review. Runtime log verification deferred to next prod deploy (requires checking `_refresh` output for the `"TD-3 cache: populated pipeline_cache key=%s"` debug log line).
